# Environment references

The catalog is an index. Each Environment may have an independent research
reference for its task, Policy-visible contract, evaluation measure, evidence,
and interpretation.

References begin as concise summaries and grow only when implementation-backed
material is available. Figures, explanatory video, and focused interactive
artifacts may be embedded alongside the Markdown narrative.

For the normative extension boundary, see the
[Benchmark authoring guide](/docs/authoring/).
